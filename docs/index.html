在终端里
连接你的评测平台

NoldOJ CLI 是 NoldOJ 评测平台的跨平台命令行客户端。它自身不包含题目或数据，需要先配置一个可访问的站点地址和私人令牌，之后才能在终端里管理题目、提交代码、打比赛，或像 gh api 一样直接请求该站点的任意接口。

C++17 WinHTTP / libcurl 私人令牌认证 JSON / CSV / ZIP 导出 脚本友好
查看命令行手册 浏览源码
noldoj — bash
# 配置站点与私人令牌
noldoj site add --name main \
  --url https://oj.example.com/api/v1 \
  --token <PAT>

# 查看当前凭据
noldoj auth tokeninfo

# 浏览题目并提交代码
noldoj problem list --page 1 --limit 20
noldoj submission create \
  --problem-id 1001 --language cpp \
  --source-file main.cpp --watch

# 像 gh api 一样直接请求
noldoj api -X GET /problems -f page=1
noldoj api /problems -X POST \
  -F title=示例题目 -F is_public=true

三步开始

下载或自行构建，添加站点，然后就可以开始使用。

STEP 01

获取可执行文件

# 从 Releases 下载
# 或从源码构建
cmake -S main -B build -G Ninja
cmake --build build
STEP 02

添加站点

noldoj site add --name main \
  --url https://oj.example.com/api/v1 \
  --token <PAT>
STEP 03

验证并开始

noldoj auth tokeninfo
noldoj problem list --page 1
noldoj help problem
凭据存放在哪里

站点地址写在 config.json；私人令牌不会明文落盘，而是用主密钥加密后存入 credentials.json（AES-128-CTR + HMAC-SHA256 认证）。两者都在本机配置目录：Linux / macOS / Termux 为 ~/.noldoj-cli/，Windows 为 %USERPROFILE%\.noldoj-cli\。

主密钥是首次启动时生成的 128 位随机密钥，保存在系统凭据库（Windows 凭据管理器 / macOS 钥匙串 / Linux Secret Service）；凭据库不可用时回退到配置目录下权限为 0600 的 master.key。用 noldoj config path 查看实际位置；令牌不会上传到任何地方，临时使用可用 --access-token 覆盖而不落盘。
